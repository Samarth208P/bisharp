# Public testnet deployment

Hosted frontend: [bisharp.netlify.app](https://bisharp.netlify.app/).

Both contracts were deployed using the configured testnet wallet and have
**exact-match Sourcify verification**. The OP Sepolia pool was seeded with at most
0.03 test ETH and the matching unbacked bUSD test token.

| Setting | Network | Address |
| --- | --- | --- |
| SourceEscrow | Ethereum Sepolia, 11155111 | `0x2334a8c6f8807C4bD6452199835A366Ee840D2e7` |
| DestinationExecutor | OP Sepolia, 11155420 | `0x975789FE1aF96a39efa2E8FF42e534C26bfB9670` |
| Deployment wallet / optional solver | Both testnets | `0xdA600Dcd13E8BaB17E3c5f35242d840B8c88cB92` |

**The route is not active yet. Both peers are zero and pairing awaits explicit
approval.** Pairing permanently binds these addresses and burns the bootstrap
pairing authority. Do not enable this route in Netlify until both pairing
transactions and the route verifier succeed. A live CCIP order round trip has
not been performed.

Public receipts (including two reverted initial source-token deployment attempts)
are in `public-transactions.json`. Contract, pool and token addresses are in
`source.json` and `destination.json`. `public-status.json` records checks and
Sourcify verification results. Predicted simulation addresses are never sufficient
as deployment evidence.

The original Foundry script gas allowance was below the source RPC deployment
requirement. Successful deployment used the simulated transaction plan with
RPC-estimated gas and per-transaction receipt/nonce checks. Private keys, raw
broadcast/cache files and RPC credentials remain Git-ignored. Public manifests
contain no credentials.

Local demo manifests are generated by `npm run demo:local` or
`npm run test:integration` and remain Git-ignored. Local transport is a fixture,
not evidence of public CCIP delivery. The bUSD test tokens are permissionless
unbacked faucets; this deployment is not approved for real funds.
